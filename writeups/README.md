# Write-ups

Documentation of my hands-on work through OverTheWire Bandit and other labs as
part of a self-directed cybersecurity program.

These entries intentionally show a progression in style. Earlier write-ups are
exploratory learning notes — figuring things out for myself. Later entries adopt
an incident-report format (Objective, Environment, Actions Taken, Result,
Takeaway) as I shifted toward analyst-style documentation and communicating work
the way it's done on a team.

## Format
Newer write-ups follow a consistent structure:
- **Objective** — what the task required
- **Environment** — the system/context
- **Actions taken** — chronological account of what I did and how I reasoned through it
- **Result** — outcome
- **Takeaway** — the reusable lesson
