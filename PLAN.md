# 12-Week Cybersecurity & AI Study Plan

A self-directed program to build job-ready security skills plus an AI-security
specialization, using entirely free resources. Progress is tracked in this repo
(`notes/`, `writeups/`, `labs/`, `projects/`).

## Daily structure
Each weekday runs like a school day with focused periods:

- **Security** — CompTIA Security+ preparation
- **Linux & command line** — daily hands-on practice
- **Applied labs** — TryHackMe / Hack The Box, committed as write-ups
- **AI / red-teaming** — LLM security, tools, and a fine-tuning track
- **Study hall** — write up and commit the day's work

## The arc

| Weeks | Focus | Milestone |
|-------|-------|-----------|
| 1–2   | Security Domains 1–2; OverTheWire Bandit; TryHackMe fundamentals; LLM basics | Portfolio live |
| 3–4   | Vulnerabilities & architecture; web wargames; OWASP LLM Top 10 + MITRE ATLAS | Fortinet FCF earned |
| 5–6   | Security operations; Hack The Box; automated LLM scanning on local models    | Signature project started |
| 7–8   | Program management; a local model fine-tune; home-lab WiFi capstone           | Model published |
| 9–10  | Practice exams; CompTIA Security+; choose a specialization lane               | Security+ passed |
| 11–12 | Lane deep-dive; documented red-team capstone; applications                    | Portfolio complete |

## Toolbox (all free)

- **Security:** [Professor Messer](https://www.professormesser.com/), Fortinet FCF, [TryHackMe](https://tryhackme.com/), [Hack The Box](https://www.hackthebox.com/)
- **Linux:** [OverTheWire](https://overthewire.org/wargames/) (Bandit, Natas)
- **Web & AI security:** [PortSwigger Academy](https://portswigger.net/web-security), [OWASP LLM Top 10](https://genai.owasp.org/llm-top-10/), [MITRE ATLAS](https://atlas.mitre.org/)
- **AI:** [Karpathy — Zero to Hero](https://karpathy.ai/zero-to-hero.html), [Hugging Face](https://huggingface.co/), Garak, Promptfoo, Unsloth

## Capstone
Build and document a local AI security assistant (an agent wired to security
tooling), then red-team it — combining hands-on security work with AI development.
