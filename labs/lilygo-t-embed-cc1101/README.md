# Lab — LilyGo T-Embed CC1101 Plus

## Device
LilyGo T-Embed CC1101 Plus — ESP32-S3, CC1101 sub-GHz, nRF24L01, PN532 NFC, IR,
WiFi/BLE 5, 1.9" IPS display, 1300mAh LiPo, 16MB Flash/8MB PSRAM.

## Firmware
Capibara Zero — open-source multi-tool firmware for the T-Embed CC1101 Plus.

## Purpose
Document the build, firmware flash, configuration, and authorized lab use of the
LilyGo T-Embed as a portable RF/wireless security testing device. Compare
capabilities against the Flipper Zero as part of the DIY pentest hardware project.
